# Database notes

The runnable web demo initializes a local SQLite database automatically on first launch. It creates tables for employees, shifts, attendance and leave requests and inserts small demo records.

The project review presentations describe a larger 12-table normalized design with roster, attendance punches, daily summaries, overtime, approvals, holidays and leave balances. That full PostgreSQL/MySQL academic schema is not silently represented by this lightweight demo schema. Use the presentation's database scripts if your assignment specifically requires the 12-table schema.
